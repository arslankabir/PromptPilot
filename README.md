# Referral Tracking and Prompt Analysis Dashboard

## Project Overview
This is a comprehensive dashboard application designed for managing referral campaigns, creating prompts, and performing in-depth analysis. The project leverages modern web technologies to provide a robust platform for tracking, analyzing, and optimizing referral programs.

## Key Features

### 1. Campaign Management
- Create and manage multiple referral campaigns
- Track campaign performance and metrics
- Filter and view campaign details

### 2. Prompt Creation and Analysis
- Build sophisticated prompts for surveys and research
- Generate detailed analyses based on prompt responses
- Duplicate, edit, and manage prompts efficiently

### 3. User and Referral Tracking
- Monitor user signups through referral links
- Track rewards associated with referral campaigns
- Manage user lists and referral interactions

### 4. Email and Communication
- Send targeted emails for campaigns
- Manage email recipients based on campaign criteria

## Technical Architecture

### Frontend
- React (TypeScript)
- React Bootstrap
- Chart.js for data visualization
- State management using React Hooks

### Backend
- AWS Services (Cognito, DynamoDB)
- RESTful API endpoints
- Authentication and authorization

## Development Setup

### Prerequisites
- Node.js (v16+)
- npm
- AWS Account (optional, for full functionality)

### Installation
1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (check .env.example)
4. Run the application: `npm start`

### Available Scripts
- `npm start`: Runs the app in development mode
- `npm test`: Launches the test runner
- `npm run build`: Builds the app for production

## Workflow: Prompt and Analysis Creation

### Prompt Creation Process
1. Navigate to Prompt Creation section
2. Design survey questions
3. Configure prompt parameters
4. Save and manage prompts

### Analysis Generation
1. Apply created prompt to target group
2. Collect survey responses
3. Generate comprehensive analysis report
4. Visualize results using interactive charts
